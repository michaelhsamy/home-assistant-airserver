# AirServer Connect

Control multiple AirServer Connect devices from Home Assistant via MQTT
discovery. Each device gets **Livestream** and **RTSP output** switches;
**End session**, **Reboot**, and **Power off** buttons; **AirPlay**,
**Google Cast**, **Miracast**, and **Livestream quality** selects; and
diagnostic sensors for last boot, firmware, hostname, device name, cloud
organization, and time zone.

**End session disconnects all users on that AirServer and rotates its Wi-Fi
password. Reboot and Power off interrupt every session.**

Enter device addresses and API keys in the Configuration tab. See the
Documentation tab for setup and troubleshooting.
