# AirServer Connect

Control multiple AirServer Connect devices from Home Assistant. Each device gets
a **Livestream** switch, an **RTSP output** switch, and an **End session** button
via MQTT discovery.

**End session disconnects all users on that AirServer and rotates its Wi-Fi
password.**

Enter device addresses and API keys in the Configuration tab. See the
Documentation tab for setup and troubleshooting.
